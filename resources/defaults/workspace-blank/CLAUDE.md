# 项目总览

> 这是这个项目里所有 Agent 都会读的文件。用几句话写清楚项目要做什么、现在在哪个阶段。

## 目录

| 目录 | 内容 | 谁写 |
| --- | --- | --- |
| `handoff/` | 交接单：谁改了什么，谁需要跟着改 | 所有人 |
| `.nexus/` | Agent 的配置和提示词（管理软件读取） | 用户 |

每加一个 Agent，在这里补一行它负责的目录。

## 协作规则

1. **只写自己的目录。** 需要别的 Agent 改东西时写交接单，不要直接改对方的文件。
2. **交接走文件，不走聊天。** 每个 Agent 是独立的会话，彼此看不到对方的对话。改了会影响别人的东西，就在 `handoff/` 按 `_template.md` 新建一张交接单。
3. **跟进别人的交接单后登记。** 在交接单末尾的“跟进记录”追加一行；所有接收方都跟进后把 `status` 改成 `done`。
4. **不编造。** 查不到的数据、参数、文献，如实说查不到并问用户。
5. **如实报告验证程度。** 区分“写完了”“检查通过”“实际验证过”。

每个任务结束后管理软件会自动提交一次 Git，提交信息以 `[agent id]` 开头，不需要自己提交。
